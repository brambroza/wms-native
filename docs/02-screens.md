# 02 — Screen Inventory & UX Principles

## หลักการ UX (จาก Senior UX/UI)

1. **งานรายวันต้อง "สแกน → ยืนยัน" ไม่เกิน 3 แตะ** — staff ใช้ handheld มือเดียว ใส่ถุงมือ ปุ่มใหญ่ ≥ 56px, ตัวอักษรตำแหน่ง ≥ 32px
2. **บอกทีละงาน (One task at a time)** — หน้าจอ staff แสดง "ไปที่ไหน / หยิบอะไร / วางที่ไหน" ไม่ต้องอ่านตาราง
3. **2D เป็นหลักบน handheld, 3D บนแท็บเล็ต/desktop** — 3D หนักและตีความยากตอนเดินในคลัง ใช้สำหรับวางแผนและโชว์ตู้
4. **สีสถานะชุดเดียวทั้งระบบ**: ว่าง=เทา, มีของ=น้ำเงิน, จองแล้ว=ม่วง, Hold/ปัญหา=แดง, เสร็จ=เขียว, กำลังทำ=เหลือง
5. **เสียง + สั่น** เมื่อสแกนถูก/ผิด (ไม่ต้องมองจอ)
6. **ภาษาไทยเป็นค่าเริ่มต้น** สลับอังกฤษได้ (เอกสารส่งออกเป็นอังกฤษ)
7. **Offline-tolerant**: สแกนต่อได้เมื่อ Wi-Fi หลุด แล้ว sync ทีหลัง (แสดง badge "รอส่ง N")

## Web (Manager / Director) — React TSX

| # | หน้าจอ | ผู้ใช้หลัก | เนื้อหา |
|---|---|---|---|
| W1 | Dashboard วันนี้ | Manager, Director | ตู้วันนี้ (progress bar ต่อตู้), รถจากสาขาที่กำลังมา, งานค้าง, % เต็มตู้เฉลี่ย, ปัญหาเปิดอยู่ |
| W2 | Onhand (ตาราง + 2D + 3D) | Manager | ค้นหา SKU/ลูกค้า/Lot, สลับมุมมอง, ฟิลเตอร์คลัง/สถานะ, ATP |
| W3 | Packing Plan — รายการ | Manager | สถานะตาม state machine, ETD, ลูกค้า, vendor, จำนวนตู้ |
| W4 | Packing Plan — สร้าง | Manager | ซ้าย: ATP พร้อมเลือก, ขวา: ตะกร้า + เกจเต็มตู้สด, เลือก source mode |
| W5 | Packing Plan — Import | Manager | ลากไฟล์, เลือก vendor template, preview + error รายบรรทัด |
| W6 | Container Fit 3D | Manager | 3D ตู้ + % ปริมาตร/น้ำหนัก + คำแนะนำ + ลำดับโหลด, เปลี่ยนประเภทตู้ |
| W7 | อนุมัติ | Manager / ผู้มีสิทธิ์ | สรุป, diff กับ version ก่อน, ปุ่มอนุมัติ/ตีกลับ |
| W8 | Loading Monitor (เรียลไทม์) | Manager, Director | การ์ดต่อตู้: 3D ระบายสีของที่โหลดแล้ว, timeline สแกน, รูป, seal |
| W9 | Transfer สาขา → กลาง | Manager | ใบโอน, สถานะรถ, ASN vs รับจริง |
| W10 | ตั้งค่าผังคลัง | Admin | zone/rack/bin + ขนาด → สร้าง 2D/3D อัตโนมัติ |
| W11 | Master data | Admin | SKU + ขนาดกล่อง/พาเลท, ประเภทตู้, vendor import template |

## Mobile (Staff) — React Native

| # | หน้าจอ | เนื้อหา |
|---|---|---|
| M1 | หน้าแรก "งานของฉัน" | ปุ่มใหญ่: รับของ / วางของ / หยิบ / โหลดตู้ / นับ + badge จำนวนงาน |
| M2 | รับ FG จากไลน์ผลิต (สาขา) | เลือก SKU, Lot, จำนวน → พิมพ์ LPN |
| M3 | รับของจากรถสาขา | เลือกรถ/ASN → สแกน LPN → นับครบ/ขาด/เกิน |
| M4 | วางของ (Putaway) | ตำแหน่งแนะนำตัวใหญ่ + 2D mini map + ทางเลือก 2 อันดับ → สแกนตำแหน่ง |
| M5 | หยิบ (Pick) | งานต่อไป: ตำแหน่ง, SKU, จำนวน, เส้นทาง 2D → สแกนตำแหน่ง → สแกน LPN → สแกน lane |
| M6 | โหลดตู้ | ลำดับพาเลทถัดไป + ภาพตำแหน่งในตู้ (2D side view / 3D บนแท็บเล็ต) → สแกน, ถ่ายรูป checkpoint, ใส่ seal |
| M7 | แจ้งปัญหา | ถ่ายรูป + เลือกเหตุผล (เสียหาย, ไม่พบของ, ผิด lot) |
