# 08 — UX/UI v3: Clean SaaS (ทิศทางปัจจุบัน)

> ทำตามภาพ reference ที่ผู้ใช้ส่งมา (dashboard ERP/การเงินโทนสว่าง) — ใช้แทน v2 สำหรับหน้าตา; ความสามารถ AI จาก `07-ux-v2-autopilot.md` ยังอยู่ แต่แสดงแบบเรียบในการ์ด
> Mockup: แคนวาส "WMS FG Export Mockups" หน้า **v3 · Clean SaaS**

## องค์ประกอบหลัก
- พื้นเทาอ่อน + การ์ดขาว มุมโค้ง 14px, เส้นขอบบาง ไม่มีเงา (ยกเว้น popover บน 3D)
- Sidebar ขาว: โลโก้ → กลุ่ม "หลัก" / "อื่น ๆ" → เมนูย่อยเยื้อง → การ์ดผู้ใช้ด้านล่าง; เมนูที่เลือก = พื้นฟ้าอ่อน + ตัวอักษรน้ำเงิน
- Header หน้า: ชื่อหน้า + breadcrumb, ปุ่มค้นหา/แจ้งเตือนทรงสี่เหลี่ยมมน
- KPI card: ชื่อ + ⋮ → ตัวเลขใหญ่ → บรรทัดเทียบ + chip delta สีเขียว/เหลือง
- ตาราง: หัวพื้นเทาอ่อน, ⇅ เรียงได้, checkbox, status pill, tabs นับจำนวน, ค้นหา + ตัวกรอง, pagination
- แถบสัดส่วนสถานะ (segmented bar) สำหรับภาพรวมแผน
- **ภาพรถหัวลาก + ตู้ด้านข้าง** แสดง % โหลดด้วยสีเติมในตู้ — ใช้ใน Dashboard, หน้าโหลด, การ์ดเลือกตู้ (ย่อ)
- AI แสดงเป็น chip สีม่วงอ่อน "AI" + ข้อความแนะนำ + ปุ่มอนุมัติ ไม่ใช้ธีมหรือพื้นที่แยก

## Tokens
| Token | ค่า |
|---|---|
| ground / card / border / divider | `#F3F5F8` / `#FFFFFF` / `#E6EAF0` / `#EEF1F5` |
| text / secondary / muted | `#1B2430` / `#3A4553` / `#6B7685` |
| primary (ปุ่ม) / primary soft / link | `#1C74C4` / `#E6F2FD` / `#1567B4` |
| data blue (กราฟ, เติมตู้) | `#4DA3F0` |
| success / warn / danger (pill bg · fg) | `#E7F7EE·#1C7C47` / `#FFF4DE·#8A5A00` / `#FDECEC·#A8322A` |
| AI | `#F0ECFD·#5B44B8` |
| font | Anuphan (ไทย+อังกฤษ), ตัวเลข tabular |

ปุ่มหลักใช้ `#1C74C4` (ไม่ใช่ฟ้าสว่าง) เพื่อให้ตัวอักษรขาวผ่าน contrast
